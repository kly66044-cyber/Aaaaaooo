بوت إدارة وحماية مجموعات تيليجرام

وظيفته الأساسية إدارة المجموعة تلقائياً، ومراقبة الرسائل، ومكافحة السبام والإعلانات والكلمات الممنوعة، وتنظيم دخول الأعضاء وخروجهم، وإرسال الترحيبات والتنبيهات والرسائل الدورية.


## 1. الحماية ومراقبة الرسائل

- منع الروابط والإعلانات

يگدر يراقب الروابط المنشورة بالمجموعة، ويحذف الروابط غير المسموحة والإعلانات والترويج، مع إمكانية تحديد نطاقات مواقع مسموح بيها.

- مكافحة السبام والتكرار

يراقب إرسال عدد كبير من الرسائل خلال فترة قصيرة. مثلاً، بالإعدادات الافتراضية، إذا انرسلت 6 رسائل خلال 8 ثوانٍ، ممكن يطبّق كتم لمدة 10 دقائق، حسب طريقة احتساب الرسائل وشروط الفلتر.

- حظر الكلمات والشتائم

يحتوي على نظام لإضافة كلمات وعبارات ممنوعة. إذا كتب عضو كلمة محظورة، يستطيع البوت حذف الرسالة وتطبيق الكتم المحدد إلها، أو الحذف والتنبيه فقط حسب الإعداد.

- التعامل مع المخالفات

يدعم التحذيرات، وتحديد عدد التحذيرات المسموح، وتطبيق عقوبة عند الوصول للحد، وإلغاء التحذيرات، وفك الكتم والحظر وطرد العضو.

ملاحظة: لازم البوت عنده صلاحيات كافية بالمجموعة. مثلاً، حذف الرسائل وكتم الأعضاء وحظرهم يحتاج صلاحيات إدارية مناسبة.

## 2. الترحيب بالأعضاء الجدد والتحقق منهم

- رسائل الترحيب

يرسل رسالة تلقائية للعضو الجديد، ويقدر يستخدم اسمه ونص ترحيب مخصص وصورة أو فيديو، مع أزرار وروابط تحت الرسالة.

- التحقق من الأعضاء الجدد (Captcha)

يطلب من العضو الضغط على زر لإثبات أنه تفاعل مع التحقق. إذا ما تحقّق ضمن المهلة المحددة، يحاول البوت إخراجه من المجموعة.

- رسائل المغادرة

يرسل رسالة وداع عند مغادرة عضو، ويقدر يحذف إشعارات الدخول والخروج الخدمية حتى تبقى المجموعة مرتبة.

## 3. أوامر الإدارة المتوفرة

هاي أهم الأوامر الموجودة فعلياً بالكود:

| الأمر         | وظيفته                                 |
| ------------- | -------------------------------------- |
| `/ban`        | حظر عضو من المجموعة                    |
| `/unban`      | إلغاء الحظر                            |
| `/kick`       | طرد عضو                                |
| `/mute`       | كتم عضو لمدة محددة                     |
| `/unmute`     | فك الكتم                               |
| `/warn`       | توجيه تحذير                            |
| `/unwarn`     | تقليل عدد التحذيرات                    |
| `/warns`      | عرض عدد تحذيرات العضو                  |
| `/resetwarns` | تصفير التحذيرات                        |
| `/del`        | حذف رسالة الأمر والرسالة المردود عليها |
| `/settings`   | فتح لوحة الإعدادات                     |
| `/lang`       | فتح إعدادات اللغة                      |
| `/help`       | عرض المساعدة                           |
| `/rules`      | عرض قوانين المجموعة                    |
| `/about`      | عرض معلومات البوت                      |
| `/start`      | بدء المحادثة الخاصة مع البوت           |

أوامر الإدارة مثل الحظر والكتم والتحذير مخصصة للمشرفين، أما `/rules` فيسمح الكود باستخدامه من الأعضاء أيضاً.

## 4. إدارة الكلمات الممنوعة

تگدر تضيف كلمات جديدة وتحدد مدة الكتم، وتقدر تحذف كلمات أو تعرض قائمة الكلمات المحظورة.

| الأمر          | الاستخدام                             |
| -------------- | ------------------------------------- |
| `/addword`     | إضافة كلمات ممنوعة                    |
| `/delword`     | حذف كلمات من القائمة                  |
| `/words`       | عرض الكلمات الممنوعة                  |
| `/clearwords`  | مسح قائمة الكلمات من خلال إجراء تأكيد |
| `/setwordmute` | تحديد مدة الكتم الافتراضية للكلمات    |

مثلاً، إذا أردت منع كلمة محددة وتطبيق كتم لمدة 30 دقيقة عند استخدامها، تقدر تستخدم صيغة مثل:

`/addword كلمة 30m`


## 5. الرسائل التلقائية والتفاعل

البوت مو بس للحماية؛ يحتوي أيضاً على وظائف لتنشيط المجموعة:

- رسائل دورية: يرسل نصائح ومعلومات ومهام قصيرة كل فترة محددة، مع إمكانية إيقافها.
- رسائل تشجيعية: يحتوي على مجموعة كبيرة من العبارات التشجيعية المصممة للتفاعل مع منشورات القناة.
- الردود التلقائية: يدعم إضافة ردود مخصصة لكلمات أو عبارات، ثم تعديلها أو حذفها.
- أزرار الروابط: يتيح إرفاق أزرار تحت رسائل الترحيب والرسائل الدورية، مثل زر القوانين أو رابط المجموعة.
- إدارة القوانين: يمكن حفظ قوانين المجموعة وتغييرها أو إيقافها.
- حذف ردود البوت تلقائياً: تقدر تحدد مدة لحذف بعض ردوده باستخدام إعداد الحذف التلقائي.

ومن الأوامر المتعلقة بهذه الوظائف:

`/periodic` — إدارة الرسائل الدورية.

`/addreply` و`/delreply` و`/replies` — إدارة الردود التلقائية.

`/setwelcome` و`/setbye` — تخصيص الترحيب والمغادرة.

`/setrules` — تغيير قوانين المجموعة.

## 6. إعدادات إضافية

يحتوي البوت أيضاً على وظائف مو ظاهرة للمستخدم العادي، منها:

- تغيير لغة واجهة البوت بين العربية والإنجليزية والفرنسية والتركية.
- تخصيص عدد التحذيرات قبل تطبيق العقوبة.
- تغيير إعدادات مكافحة السبام.
- تحديد نطاقات الروابط المسموح بها.
- تحديد وسائط الترحيب والمغادرة.
- تتبع نشاط بعض الأعضاء ومنح جوائز على شكل ألقاب أو وسوم مرتبطة بالتفاعل والاستمرارية.
- حفظ إعدادات المجموعات والبيانات في ملف JSON.
